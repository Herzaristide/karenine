# Les icônes de l'interface

Celles de la barre du bas, de ses volets et du panneau de droite : des
icônes au trait (24 × 24, trait 1,7, bouts arrondis), dessinées pour la
maquette de l'interface. Le trait est blanc ; NixIcon les recolore au thème.

Elles vivent hors de `assets/icons/`, dont `sync.sh` supprime tout ce qui
n'est pas tiré de Phosphor.
